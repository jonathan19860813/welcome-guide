How it works
  1. Fill in your details below (or tap Load example to see one). Everything saves automatically on this phone/browser only.
  2. Tap Create guest link, then send the link on WhatsApp/email or print the QR code for the unit.
  3. Guests open it in their phone browser — no app needed.

🔒 Privacy: everything you enter (Wi-Fi password, lockbox codes, address) is stored inside the link itself. Anyone with the link or QR code can read it — only share it with booked guests.

🔁 Changed something? Make a new link and QR code after every edit. Old links keep showing the old details.
